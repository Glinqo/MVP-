# Scenario Teaching Demo Guide
# 情景教学演示功能说明

## 功能入口

1. 启动项目服务后，在浏览器打开页面
2. 在左侧导航点击"角色扮演"进入情景教学
3. 推荐场景卡片会显示在最上方，点击"开始情景训练"

## 推荐演示路径

1. **打开推荐场景**：点击"传感器动作灯亮，但PLC输入灯不亮"卡片上的"开始情景训练"
2. **第一阶段先演示错误操作**：选择"直接修改PLC程序"，展示"操作过早"反馈 → 步骤不推进
3. **重新选择正确操作**：选择"检查传感器到PLC输入端之间的信号链路"，进入第二阶段
4. **第二阶段正确定位**：选择"检查PLC输入公共端和传感器输出线"，展示新增证据
5. **第三阶段先演示危险操作**：选择"不断电直接拆接公共端"，展示红色"安全操作被阻止"
6. **演示缺少验证**：选择"重新接好公共端后直接结束维修"，展示"缺少闭环验证"
7. **正确完成**：选择"断电并确认安全后重新接好公共端，再完成三联状态验证"，展示完成报告

## 功能亮点

- **现场状态**：左栏实时显示传感器动作灯、PLC输入灯、在线监控值等状态，含5种状态色（正常/异常/危险/未知/恢复）
- **操作卡片**：整张可点击卡片，含操作名称和说明，选中状态清晰
- **分类型反馈**：6种反馈类型各有独立样式——正确(绿)、过早(黄)、低效(蓝)、不安全(红)、缺少闭环(橙)、错误(灰)
- **动态证据**：右栏证据列表，新增证据1.2秒高亮动画
- **AI师傅提示**：右栏折叠式提示，默认收起，新阶段自动重置
- **操作时间线**：底部时间线按反馈类型着色编号，记录操作历史
- **闭环验证**：第三阶段强调安全隔离 → 故障修复 → 三联状态验证
- **完成报告**：模态弹窗展示故障原因、验证状态、完成项目和能力标签

## 三阶段教学流程

| 阶段 | 主题 | 正确操作 | 可选错误操作 |
|------|------|----------|-------------|
| 1/3 | 判断故障范围 | 检查信号链路 | 直接修改程序(过早)、直接更换模块(低效) |
| 2/3 | 定位具体原因 | 检查公共端和输出线 | 检查输出程序(过早)、更换整套传感器(低效) |
| 3/3 | 安全修复和闭环验证 | 断电→接好→三联验证 | 不验证直接结束(缺少闭环)、带电操作(不安全) |

## 已知边界

- 当前聚焦一个演示场景（SCN_SENSOR_LED_ON_PLC_LED_OFF），其他场景可使用相同训练工作台但字段较基础
- AI师傅提示为固定教学提示，非实时AI生成
- 操作时间线保存在前端内存，刷新后消失
- 暂未实现教师端管理界面和场景编辑器
- 推荐场景卡片内容为前端硬编码，未来可迁移到后端

## 兼容性

- 桌面端：1366×768及以上正常演示，三栏布局
- 中等屏幕（~1100px）：两栏紧凑布局
- 小屏（~760px）：单栏上下布局
- 旧场景缺少新字段时自动降级，不报错
