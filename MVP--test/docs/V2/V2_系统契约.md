# V2 系统契约

## Identity Contract
principal = { user_id, username, role, job_role }
localStorage 仅缓存，不作为权限依据

## Session Contract
Canonical Student Session ID: 统一生成
Legacy resolver: 支持历史格式
新写入数据只使用 Canonical ID

## Ability Contract
正式 Schema: knowledge/ability_nodes.json
正式 ID: rt_*, es_*, sn_*, pl_*, tr_*
正式字段: description (非 desc)

## Learning Event Contract
Source of Truth: data/sessions + learning_event_store
get_events() = { events: [...], total: ... }

## Permission Contract
Teacher-only: 岗位治理 API
Student: 只能访问自己数据
