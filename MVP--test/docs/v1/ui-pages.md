## 页面职责与核心组件

### 1. 聊天主页 `/chat`

**职责**：类 ChatGPT 的分会话聊天，第一版核心页面

```
┌─────────────┬──────────────────┐
│  会话列表    │                  │
│  (280px)    │    聊天面板       │
│             │                  │
│ [+新对话]   │  ┌────────────┐  │
│             │  │ 消息列表    │  │
│ ┌────────┐  │  │ (Markdown) │  │
│ │会话 1   │  │  └────────────┘  │
│ │会话 2   │  │  ┌────────────┐  │
│ │会话 3   │  │  │ 输入框     │  │
│ └────────┘  │  │ [发送]     │  │
│             │  └────────────┘  │
└─────────────┴──────────────────┘
```

**核心组件**：

| 组件 | 功能 |
|------|------|
| `ConversationList.vue` | 会话列表，新建/删除/重命名 |
| `ChatPanel.vue` | 消息区域 |
| `MessageItem.vue` | 单条消息（支持 Markdown） |
| `ChatInput.vue` | 输入框 + 发送按钮 |

**用户操作流程**：

1. 进入页面 → 加载历史会话列表（左侧）
2. 点击"新对话" → 创建会话 → 自动选中
3. 选择已有会话 → 加载该会话消息 → 输入框聚焦
4. 输入文字 → 点击发送 → 左侧显示用户消息 → 右侧显示智能体回复（Markdown）
5. 不同会话切换 → 消息区域重新加载，不串流
6. 页面刷新 → 会话和消息持久化

**交互细节**（参考 ChatGPT）：
- 新会话选中时左侧高亮
- 无消息时显示"欢迎语 + 建议问题"
- 输入框按 Enter 发送，Shift+Enter 换行
- Markdown 渲染：加粗、列表、代码块、引用
- 链接可点击，新窗口打开
- 自动滚到底部，用户向上滚动时不强制回底

### 2. 图谱详情页 `/graph`

**职责**：D3.js 力导向图 + 雷达图，展示岗位/个人能力

**核心组件**：

| 组件 | 功能 |
|------|------|
| `ForceGraph.vue` | D3.js 力导向图（从 graph-renderer.js 迁移） |
| `NodeDetail.vue` | 节点点击弹窗（证据链、权重、历史） |
| `RadarChart.vue` | 雷达图（可用 ECharts） |
| `GraphTabs.vue` | 岗位图谱 / 个人图谱切换 |

**用户操作流程**（学生）：
1. 进入页面 → 默认显示岗位能力图谱
2. 拖拽节点 → 松手回弹
3. 滚轮缩放 → 整体放大/缩小
4. 点击节点 → 右侧弹出详情：证据数量、置信度、来源分布
5. 点击"个人图谱" → 切换为学生图谱 + 雷达图

**用户操作流程**（教师-管理端）：
1. 显示待确认提案数量角标
2. 点击进入审核面板 → 逐条确认/驳回
3. 查看版本历史 → diff 对比
4. JD 导入输入框 → 粘贴 → 分析 → 生成提案

### 3. 排故场景页 `/scenario`

**职责**：一步步的故障诊断角色扮演

**核心组件**：

| 组件 | 功能 |
|------|------|
| `ScenarioList.vue` | 场景列表 |
| `ScenarioStage.vue` | 当前步骤（问题+选项） |
| `ScenarioResult.vue` | 完成后的复盘 |

**用户操作流程**：
1. 选择场景 → 点击开始
2. 阅读当前状态描述 → 选择一个诊断动作
3. 系统反馈判断结果 + 观察信息
4. 继续下一步 → 直到场景完成
5. 显示复盘总结 → 可追问 AI

### 5. 培养方案页 `/plan`

**核心组件**：

| 组件 | 功能 |

### 6. 智能体配置 `/agent/config`（管理员）

**职责**：后台管理表格 + 表单

复用 RuoYi 代码生成器的表格 + 表单模式。

**字段**：名称、描述、头像、系统提示词、模型名称、温度、最大历史消息数、启用状态。

### 7. 调用统计 `/statistics`（管理员）

**核心组件**：

| 组件 | 功能 |
|------|------|
| `SummaryCards.vue` | 总调用次数、成功率、平均延迟 |
| `TrendChart.vue` | 按天/小时的调用趋势（ECharts） |

### 8. 调用日志 `/statistics/logs`（管理员）

**核心组件**：

| 组件 | 功能 |
|------|------|
| `LogTable.vue` | 表格：用户、智能体、模型、Token、耗时、状态 |

## 响应式布局

- 桌面（>= 1200px）：聊天页左右分栏 280px + 1fr
- 平板（768-1199px）：会话列表可折叠
- 手机（< 768px）：不做重点适配，保证基本可读
